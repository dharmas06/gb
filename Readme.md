Gb cli

Cli tool to interact with GB server(https://github.com/dharmas06/gbserver). Implemented using cobra.


$gb is a CLI library for Github that allows users to manage their git repos.

Usage:
  gb [command]

Available Commands:
  cleanup     cleanup repos, branches and pull requests
  close       Close pull requests
  completion  Generate the autocompletion script for the specified shell
  create      Create repos, branches and pull requests
  delete      Delete repos, branches and pull requests
  help        Help about any command
  list        list repos, branches and pull requests

Flags:
  -h, --help     help for gb
  -t, --toggle   Help message for toggle

Use "gb [command] --help" for more information about a command.
